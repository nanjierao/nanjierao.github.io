# inbox/

Drop files here for the next Claude Code session: a Zhihu draft (.md) and its images, the public
CV PDF, photos for the site. Upload them with GitHub's web page (Add file → Upload files) or the
GitHub mobile app, then tell the session what they are for (for a blog post: `/post-zhihu
<zhihu-url>`). The session moves each file where it belongs and leaves only this README here.

Everything in this repository is public, including files that pass through this folder.
